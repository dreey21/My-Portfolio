# My portfolio site

Hi, this repo is the source for my personal portfolio: a single-page site built with **Vue 3** and **Vite** where I introduce myself, the kind of systems I work on, and a few projects I am proud of.

I spend most of my time on the backend (Laravel, PHP, APIs, MySQL), but I care about how things feel in the browser too. This site is partly a playground for that: scroll reveals, a tabbed project grid, and a layout I wanted to feel calm and readable rather than flashy.

If you are here from a job posting or a message I sent: thanks for looking. The live content (bio, services, skills, project cards) mostly lives in `src/data/portfolio.js` and the section components under `src/components/` — tweak those if you fork this for your own use.

## Run it locally

```bash
npm install
npm run dev
```

Build and preview a production bundle:

```bash
npm run build
npm run preview
```
